# Bank Account Management System

Users can add money to their account through credit transactions, withdraw money through debit transactions, and view the updated total balance after every transaction.

## Features
- Credit money into the bank account
- Debit money from the bank account
- Display current account balance
- Track basic account transactions
- Simple command-line interface

## How It Works
1. User enters transaction details.
2. The system processes credit or debit operations.
3. The account balance is updated automatically.
4. The updated total amount is displayed.

## Technologies Used
- Programming Language: (python)
- Interface: Command Line Interface (CLI)
